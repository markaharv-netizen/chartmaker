# Tesla Delivery Growth (YoY %)

Library PNG for My Bot's Sheets tab "Tesla Delivery Growth" (bot3 gid `1642407363`, native chart `1618236387`). The image is Steve's static annual Python render (cream background, teal positive bars, terracotta negative bars for 2024 and 2025). The native Sheets chart cannot color negative bars red, so the library serves this PNG. The Google Sheet tab is real, so Open in Sheets stays on. Monday's importer will not overwrite this PNG (`KEEP_MANUAL_PNGS`). There is no refresh routine.

Current image: annual vehicle deliveries for 2013–2025 (growth plotted 2014–2025).
