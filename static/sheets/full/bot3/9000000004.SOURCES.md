# Founder-CEO Tier List — photo sources

All portraits (except one placeholder) were downloaded from Wikimedia Commons
and visually checked against the file-page caption / Wikipedia lead image.
They were then cropped to head-and-shoulders and converted to a high-contrast
grayscale rendering in Python (PIL). No likenesses were invented.

Final card committed in Chartmaker: `static/sheets/full/bot3/9000000004.png` (1840×3571, no watermark).
Build script (not run on Monday): `/workspace/ceo_tier/make_ceo_tier_card.py`.
This credits file sits beside the PNG as `static/sheets/full/bot3/9000000004.SOURCES.md`.
